# زر الواتساب العائم — Go Online

ملف `sticky-whatsapp-button.html` هو الكود الكامل جاهز للّزق (HTML + CSS + JS بملف واحد).

## وين تلزقه في GHL

- **لصفحة/فَنِل واحد:** Funnel → Settings → **Custom Code** → *Footer Tracking Code*
- **لكل الموقع:** Sites → **Custom Code** → *Footer*

انسخ محتوى الملف كامل والزقه كما هو.

> **مهم:** لا تحطه داخل عنصر Custom HTML جوّا سكشن. سكاشن GHL بتستخدم `transform`
> واللي بيكسر الـ `position: fixed` — الكود بيحلّها بنقل الزر تحت `<body>`، بس اللزق
> بالـ Footer أنضف.

## تعديلات سريعة

| بدك تغيّر | روح لـ |
|---|---|
| رقم الواتساب | `href` تبع `#sticky-whatsapp-btn` **بس** — الفقاعة بتاخد نفس الرقم تلقائياً |
| نص الفقاعة | النص داخل `<a class="wa-bubble-text">` |
| لون الزر والـ glow | `--wa-green` و `--wa-glow` (نفس اللون بس RGB) |
| حجم الزر ومكانه | `--wa-size` / `--wa-right` / `--wa-bottom` |
| محاذاة ذيل الفقاعة | `--wa-tail` |

الموبايل عنده override خاص بنفس المتغيرات تحت `@media (max-width: 767px)`.

## زر الإغلاق (×)

فوق الفقاعة من جهة الشمال في × صغير. لما الزائر يضغطه:

- الفقاعة بتختفي بحركة ناعمة، **والدائرة الخضرا بتضل** ظاهرة.
- بنخزّن الاختيار بـ `sessionStorage` — يعني بتضل مخفية وهو يتنقل بين صفحات الموقع،
  وبترجع تظهر بزيارة جديدة (تبويب جديد أو بعد ما يسكّر المتصفح).

**بدك الفقاعة ما تنسكر أبداً؟** احذف عنصر `<button class="wa-bubble-close">` من الـ HTML.

**بدك الإخفاء يضل للأبد؟** بدّل `sessionStorage` بـ `localStorage` بالسكربت (مكانين).

## نصوص بديلة للفقاعة

- `عندك مشكلة بالدفع؟ تواصل معنا واتساب` ← الافتراضي
- `ما زبطت معك عملية الدفع؟ احكي معنا`
- `واجهتك مشكلة بالطلب؟ راسلنا هون 👋`
- `محتاج مساعدة؟ فريقنا متاح الآن`
- `Payment issue? Chat with us on WhatsApp` ← للصفحات الإنجليزية

النص بيضلّ سطر واحد على الديسكتوب لحد ~320px، وبينزل لسطرين لحاله على الموبايل.

## شو بيعمل الكود

- فقاعة نص فوق الزر مع ذيل بيأشّر عليه، بتظهر بحركة fade + slide بعد ٠٫٩ ثانية.
- **Glow** على الزر: نبض `box-shadow` + حلقة خارجية بتتوسّع وتختفي.
- **Glow** أخف على الفقاعة نفسها.
- الضغط على الفقاعة بيفتح الواتساب زي الزر بالضبط (الفقاعة رابط لحالها).
- زر × لإخفاء الفقاعة مع حفظ الاختيار للجلسة.
- بيحترم `prefers-reduced-motion` — بتوقف الحركة ويضل الـ glow ثابت.
- بيشيل أي نسخة مكررة لو انلزق الكود مرتين بالغلط.
- ما بيعتمد على `DOMContentLoaded` لحاله، لأن GHL بحقن الكود بعد ما يخلص أحياناً.
- كل الوصول للـ `sessionStorage` داخل `try/catch` — عشان التصفح الخاص ما يكسر السكربت.

## مجرَّب على

Chromium headless — صفحة فيها سكشن بـ `transform` يحاكي GHL:

- **الاتجاه:** RTL و LTR (الفقاعة بتتمدد لليسار بالحالتين)
- **العروض:** 320 / 360 / 390 / 1280
- **الإغلاق:** ضغطة مبرمجة على الـ × ← الفقاعة اختفت، الدائرة ضلّت، والقيمة انحفظت بالـ session
