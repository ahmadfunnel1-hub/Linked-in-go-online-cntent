# تراكر داليا ← مهام وتنبيهات GoHighLevel

| الملف | شو هو |
|---|---|
| `apps-script/Code.gs` | الـ Apps Script الأصلي + 3 أسطر جديدة بـ `doPost` (بتنادي التنبيهات لما تتغير الحالة من التراكر) |
| `apps-script/Notifier.gs` | **الملف الجديد**: بيعمل Tasks بـ GHL لكل شخص حسب التايم لاين + إيميلات |
| صفحة التراكر (Custom HTML بـ GHL) | ما تغيّرت، ما في شي تعمله فيها |

## شو بيصير حسب التايم لاين

| متى | شو بيصير |
|---|---|
| قبل `Start` بيوم (`LEAD_DAYS`) | Task بـ GHL للشخص بعمود Owner التاني، وموعد التسليم = يوم `End` الساعة 5 |
| مهمة بلّشت أو متأخرة وما إلها Task | بتنعمل فوراً بأول تشغيل |
| الحالة صارت Done (من التراكر أو من الشيت) | الـ Task بتنسكّر بـ GHL لحالها. وإذا رجعت Pending، بترجع تنفتح |
| مهمة إلها `Dependency` والمهام اللي قبلها خلصت | بتنعمل فوراً «🔔 دورك الآن» + إيميل للشخص |
| عدّى `End` وما خلصت | Task «⚠️ متأخرة» للمدير (`MANAGER`)، مرة وحدة لكل مهمة |
| كل يوم الساعة 9 | إيميل لكل شخص فيه: شو بيبدأ اليوم/بكرا، شو بينتهي اليوم، وشو متأخر |
| شخص `Dalya` (فريق العميل) | الـ Task بتروح لـ `CLIENT_FOLLOWUP` باسم «👤 متابعة مع العميل» |
| تغيّر الشخص المسؤول | الـ Task القديمة بتنسكّر، وبتنعمل وحدة جديدة للشخص الجديد |

## خطوات التركيب

### 1) من GHL (الساب أكاونت اللي فيه الفريق)
1. **Settings ← Private Integrations ← Create new integration**، سمّيه `Project Tracker`، واختار الصلاحيات:
   `View Contacts`، `Edit Contacts`، `View Users`. انسخ التوكن (بيبلّش بـ `pit-`).
2. **Location ID**: من **Settings ← Business Profile**، أو من الرابط `.../location/XXXX/...`.
3. (مستحسن) اعمل كونتاكت اسمه «مشروع داليا» وانسخ الـ ID تبعه من الرابط. كل المهام بتنحط عليه.
   إذا ما عملته، السكربت بيعمله لحاله.

### 2) من Apps Script
4. بمشروع الـ Apps Script اضغط **＋ ← Script**، سمّيه `Notifier` والصق `Notifier.gs`.
5. بدّل `Code.gs` بالنسخة الجديدة. التغيير الوحيد 3 أسطر بـ `doPost` بعد `setValue`.
6. **⚙️ Project Settings**:
   - **Time zone**: توقيت الفريق (مثلاً `Asia/Amman`).
   - **Script Properties ← Add**: `GHL_TOKEN` و `GHL_LOCATION_ID`، والاختياري `GHL_CONTACT_ID`.
7. فوق بـ `Notifier.gs` عبّي هدول:
   - `CLIENT_FOLLOWUP`: مين بيتابع مع داليا (اسمه أو إيميله بـ GHL). **لازم تعبّيه.**
   - `MANAGER`: مين بيوصله تنبيه التأخير. إذا بتخليه فاضي، ما في تنبيه تأخير.
   - `TRACKER_URL`: رابط صفحة التراكر (بينحط جوّا المهمة وبالإيميل).

### 3) التشغيل (من المحرر: اختار الفنكشن واضغط ▶ Run)
8. `setupNotifier`: أول مرة بيطلب صلاحيات، وافق عليها. بيطبع مستخدمين GHL وجنب كل اسم بالشيت ✅ أو ❌.
   إذا في ❌، زبّطه بـ `TEAM`، مثلاً `"Otaibi": "name@adscope.com"`، وشغّله كمان مرة.
9. `testNotifier`: تجربة بدون ما يبعت ولا شي، بيطبع شو رح يصير اليوم.
10. `installNotifier`: بيركّب التشغيل اليومي + مزامنة تعديلات الشيت، وبيعمل أول دورة حقيقية.
11. **Deploy ← Manage deployments ← ✏️ (عدّل الـ deployment الموجود) ← Version: New version ← Deploy.**
    ⚠️ لا تعمل *New deployment*، لأنه بيغيّر رابط الـ `/exec` وبيوقف التراكر.
    بدون هالخطوة، زر Done بالتراكر ما رح يسكّر مهمة GHL إلا تاني يوم الصبح.

## ملاحظات
- **أول تشغيل** (اليوم 22 نوفمبر) رح يعمل 7 مهام للمهام المفتوحة/المتأخرة: #3، #7، #8، #9، #11، #12، #14.
  وإذا `MANAGER` معبّى، بيعمل كمان 7 تنبيهات تأخير.
- **«دورك الآن»** بيشتغل بس إذا عمود `Dependency` معبّى برقم المهمة اللي قبلها (مثلاً لـ #13 Meta Ads Launch اكتب `12`).
  هلق العمود فاضي بالشيت.
- **تغيير اسم المهمة** بالشيت = مهمة جديدة بـ GHL. القديمة سكّرها بإيدك.
- **الإيميلات** بتطلع من حساب Gmail اللي مركّب السكربت. لتوقيفها: `EMAIL_DIGEST: false`.
- **لإيقاف كل شي**: شغّل `removeNotifier`. المهام الموجودة بـ GHL بتضل.
- **تنبيه GHL نفسه**: المهمة بتطلع بـ Tasks وعلى الكونتاكت. إذا بدك واتساب/SMS للشخص، فعّل إشعارات
  المهام من بروفايل كل مستخدم، أو بنعملها خطوة جاية بـ Workflow.
