# 05 — إستراتيجية الفانل

> المصادر: الأفاتار (`01`)، العرض (`02`)، وملف الهوية والعرض المرفق (Brand & Offer – نسخة 11 نوفمبر 2026).
> الهدف: **بيع مباشر + بناء جمهور قبل البيع** • الوعي: يعرف المشكلة جيداً، يعرف أن هناك حلولاً لكن أول مرة يرى حلاً بهذه الشمولية.

## ⚠️ قيود من ملف الهوية تحكم اختيار الفانل
| القيد في الملف | أثره على الفانل |
|---|---|
| السعر يبدأ **$39/شهر** + **تجربة 14 يوم مجاناً بدون بطاقة** | منتج Self-serve منخفض السعر → لا يتحمّل تكلفة مكالمة مبيعات لكل عميل |
| **ممنوع:** "احجز استشارة مجانية"، "اترك رقمك وبنرجعلك"، اجتماعات مجانية | يُستبعد Strategy Call Funnel، ولا نماذج "نتواصل معك" |
| CTA المعتمد: **"ابدأ 14 يوم مجاناً"** + ثانوي **"شوف كيف بيشتغل"** | الفانل كله يصبّ في تسجيل التجربة + فيديو عرض |
| فيديو 30 ثانية جاهز، صوت بشري، **بدون موسيقى**، لا سعر في الفيديو | يدعم VSL/فيديو عرض قصير |
| حقل الهاتف **باختيار كود الدولة** (لا تفترض الأردن) | ينطبق على كل نماذج التسجيل |
| **لا تدّعي:** أن Syncro Ads يقرأ المبيعات ويرسلها للإعلانات؛ KDS؛ إرسال واتساب آلي؛ أرقام عملاء بدون موافقة | ⚠️ يتعارض مع جزء من "الحلقة المغلقة" في `02` (ربط فواتير الكاشير بالإعلانات). الصحيح حسب الملف: **الطلبات الأونلاين من صفحة المحل** تُرسل لـ Meta/GA4/Google Ads. يجب تعديل `02` و`03` قبل كتابة أي نص للفانل |
| سلّم الترقية: الأساس → إضافات → **313 تدير إعلاناتك $400/شهر** → **جلسة خبير مدفوعة $40/30د (آخر خيار)** | يحدد أماكن الـ Upsell والـ Downsell بالضبط |

## 1. الفانل المختار: **VSL Funnel → تجربة مجانية (Product-Led)**
_(فيديو مبيعات قصير يقود إلى "ابدأ 14 يوم مجاناً"، ثم التحويل للاشتراك المدفوع داخل التجربة)_

### ليش هذا تحديداً؟
1. **مستوى الوعي:** العميل يعرف مشكلته ويعرف حلولاً (تطبيقات توصيل، كاشير، واتساب)، لكنه **لم يرَ كل شي بمكان واحد**. هذا "وعي بالحل لكن ليس بالآلية الجديدة" → يحتاج **عرض بصري سريع** يثبت "طلب ← طابعة ← واتساب ← ولاء" أكثر من أي نص. الفيديو يقتل الشك أسرع من صفحة طويلة.
2. **السعر منخفض ($39):** القرار "صغير" ولا يحتاج ويبينار ساعة ولا مكالمة. VSL + تجربة مجانية = أقل احتكاك ممكن.
3. **التجربة المجانية بدون بطاقة هي أقوى عرض عندك:** صاحب المطعم المحروق من الوكالات والأنظمة (الأفاتار) يقتنع بـ "جرّب بنفسك" أكثر من أي وعد. المنتج يبيع نفسه خلال 14 يوم.
4. **متوافق 100% مع قواعد البراند:** لا استشارات مجانية، CTA موحد، فيديو صوت بشري جاهز.
5. **يبني جمهور حتى لمن لم يسجل:** مشاهدي الفيديو (25/50/75%) يصبحون جمهور إعادة استهداف على ميتا بتكلفة شبه صفرية → "بناء جمهور قبل البيع".
6. **يتوسع للأربع جماهير في الملف** (فرع واحد / سلاسل / مطابخ سحابية / تجزئة) بتغيير الفيديو والعنوان فقط مع نفس المسار.

## 2. الخطة البديلة (Plan B): **Quiz Funnel — "وين طلباتك تضيع؟"**
اختبار 6–8 أسئلة (عدد الفروع، مصادر الطلبات، هل عندك سواق، كم تدفع عمولات…) → نتيجة مخصصة + فيديو للجمهور المناسب → "ابدأ 14 يوم مجاناً".

**يكون أفضل من الخيار الأول عندما:**
- تكلفة التسجيل في الـ VSL عالية لأن الجمهور بارد (لا يعرف البراند إطلاقاً) → الكويز ممتع ومنخفض الالتزام.
- تريد **تقسيم الجمهور تلقائياً للأربع شرائح** وإرسال رسائل مختلفة لكل شريحة (مثالي لـ GHL Tags).
- الهدف الأكبر في مرحلة ما **بناء قائمة** قبل البيع (إطلاق في مدينة جديدة، أو قبل حملة موسمية مثل رمضان).
- تريد بيانات سوق (كم مطعم عنده سواق؟ كم يدفع عمولة؟) لتحسين العرض والمحتوى.

> بديل ثالث للمستقبل: **Challenge Funnel** ("5 أيام: طلبات من موقعك بدل التطبيقات") عندما يتوفر جمهور كبير ومحتوى وقصص عملاء — ممتاز لبناء جمهور لكنه يحتاج جهد تشغيلي أعلى.

## 3. خريطة الفانل الكاملة

```
[إعلان ميتا/تيك توك/قوقل • محتوى • واتساب بوت]
              │                         ╲ (اختياري) [P0 حاسبة/دليل مجاني] → قائمة + إعادة استهداف
              ▼
[P1 صفحة الـ VSL] ──(شاهد ولم يسجل)──► جمهور إعادة استهداف + رسائل
              │ "ابدأ 14 يوم مجاناً"
              ▼
[P2 التسجيل: رقم الجوال + كود الدولة، بدون بطاقة]
              ▼
[P3 صفحة الترحيب + الخطوة التالية]
              ▼
[P4 الإعداد/التفعيل داخل التطبيق: منيو، رابط الطلب، ربط Sunmi]
              ▼  (أيام 1–14: رسائل تفعيل)
[P5 صفحة الترقية والدفع — نقطة البيع]  ──(لم يشترك)──► [P7 Downsell: جلسة خبير $40]
              ▼
[P6 Upsell: الإضافات / 313 تدير إعلاناتك $400]
              ▼
[P8 شكراً + تأكيد الاشتراك]
```

### تفاصيل كل صفحة
| # | الصفحة | القرار المطلوب من الزائر | جاي من ← رايح إلى | أهم عنصر | إجبارية؟ |
|---|---|---|---|---|---|
| P0 | **مغناطيس العملاء** (حاسبة "كم تدفع عمولات شهرياً" أو دليل) | يترك رقمه مقابل النتيجة | إعلان/محتوى ← P1 (عبر رسالة النتيجة) | نتيجة رقمية شخصية فورية + زر "شوف كيف بيشتغل" | اختيارية (للمرحلة 2) |
| P1 | **صفحة الـ VSL / الهبوط** | "هذا الحل لي — أبدأ التجربة" | الإعلان ← P2 | **فيديو العرض (30ث + نسخة 2–3 دقائق)** فوق الطي + زر "ابدأ 14 يوم مجاناً" + سطر "بدون بطاقة، بدون رسوم إعداد" | **إجبارية** |
| P2 | **التسجيل** | يسجّل فعلاً | P1 ← P3 | أقل الحقول: اسم المحل + رقم الجوال (**مع اختيار كود الدولة**) + نوع النشاط (للتقسيم) | **إجبارية** |
| P3 | **الترحيب / الخطوة التالية** | يبدأ الإعداد الآن لا لاحقاً | P2 ← P4 | فيديو قصير "أول 3 خطوات" + زر "ضيف المنيو" + زر واتساب للمساعدة في ربط Sunmi | **إجبارية** |
| P4 | **الإعداد والتفعيل (Onboarding)** | يوصل لأول طلب حقيقي ("لحظة الواو") | P3 ← P5 | قائمة تقدّم (Checklist): منيو ← رابط الطلب ← أول طلب تجريبي يطبع ← مشاركة الرابط | **إجبارية** (داخل المنتج) |
| P5 | **الترقية والدفع** ⭐ | **يشترك ويدفع** | P4/رسائل نهاية التجربة ← P6 | ملخص "اللي صار في تجربتك" (عدد الطلبات) + أمثلة الفواتير ($39 / $69 / $209) + دفع أونلاين | **إجبارية** |
| P6 | **Upsell بعد الدفع** | يضيف إضافة واحدة | P5 ← P8 | عرض بضغطة واحدة حسب نوعه: نقاط الولاء $15 / فرع إضافي $30 / تاسكس / **313 تدير إعلاناتك $400** | اختيارية (تُضاف بعد أول 20 مشترك) |
| P7 | **Downsell** | من لم يشترك: يحجز جلسة مدفوعة | انتهاء التجربة بدون دفع ← P5 لاحقاً | "جلسة خبير 30 دقيقة $40 نجهّز معك كل شي" (تُخصم إن اشترك؟ قرار تجاري) | اختيارية (آخر خيار حسب الملف) |
| P8 | **شكراً / تأكيد** | يشارك رابط الطلب مع زبائنه | P6 ← المنتج | خطوة واحدة: "انشر رابطك الآن" + قالب بوست/ستوري جاهز | **إجبارية** (بسيطة) |
| — | **شوف كيف بيشتغل** (Demo) | يقتنع بالتفاصيل | P1 (زر ثانوي) ← P2 | ديمو تفاعلي/فيديو أطول لكل جمهور من الأربعة | اختيارية |
| — | **صفحات الجماهير الأربع** | "هذا مصمم لنوعي" | الإعلان المخصص ← P2 | نفس P1 بعنوان ووجع وفيديو الجمهور المحدد | اختيارية (بعد اختبار P1) |

## 4. الأرقام والنقاط الحاسمة

| البند | الإجابة |
|---|---|
| **عدد الصفحات الأساسية** | **6** (P1, P2, P3, P4, P5, P8) |
| **مع الاختيارية** | **10** (+ P0, P6, P7, Demo) + صفحات الجماهير الأربع لاحقاً |
| **نقطة البيع الأساسية** | **P5 – صفحة الترقية والدفع** (نهاية التجربة أو عند الوصول لحدّ الاستخدام). P2 هي "الالتزام الصغير" وليست البيع |
| **مكان الـ Upsell** | **P6 مباشرة بعد الدفع** (إضافات ضغطة واحدة) + **داخل المنتج** بعد 30 يوم: فرع إضافي/تاسكس، وبعد 60 يوم لمن يصرف على إعلانات: **313 تدير إعلاناتك $400** |
| **مكان الـ Downsell** | **P7 عند انتهاء التجربة بدون اشتراك**: جلسة خبير $40 (آخر خيار)، أو تمديد التجربة 7 أيام لمن لم يكمل الإعداد (قرار تجاري — ليس في الملف) |

### رسائل التفعيل خلال التجربة (تربط P4 بـ P5)
| اليوم | الرسالة | الهدف |
|---|---|---|
| 0 | أهلاً + فيديو أول 3 خطوات | يبدأ الإعداد |
| 1 | "ضفت المنيو؟" + رابط مساعدة واتساب لربط Sunmi | إزالة العائق التقني |
| 3 | "جرّب طلب تجريبي واشوف الطابعة تطبع" | لحظة الواو |
| 5 | قالب ستوري جاهز لنشر رابط الطلب | أول طلب حقيقي |
| 9 | "طلباتك هالأسبوع: X" | إثبات القيمة |
| 12 | "باقي يومين" + أمثلة الفواتير | الإلحاح |
| 14 | رابط الاشتراك (P5) | البيع |
| 16 | لم يشترك → P7 | Downsell |

> ⚠️ حسب الملف، سينكرو نفسه لا يرسل واتساب آلياً — هذه الرسائل تُبنى في **GoHighLevel** (أو SMS/إيميل) وليس داخل المنتج.

### مؤشرات القياس (KPIs)
| المرحلة | المؤشر | هدف مبدئي (يُعدّل بعد أول شهر) |
|---|---|---|
| إعلان ← P1 | CTR | 1–2% |
| P1 ← P2 | نسبة التسجيل | 8–15% |
| P2 ← تفعيل | وصل لأول طلب | 40%+ |
| التجربة ← مدفوع | التحويل | 20–35% |
| بعد الدفع | Upsell | 15%+ |

## 5. قرارات مطلوبة منك قبل كتابة النصوص
1. **أي اسم وهوية نعتمد؟** الملف المرفق = "سينكرو" بلونه وشعاراته؛ الملفات `03`/`04` = "طاولة مليانة". (قلتَ إن المسمى غير مهم، لكن يلزم واحد للصفحات.)
2. **الإعلان عن الإعلانات:** نعدّل `02` لتصبح الآلية "الطلبات الأونلاين تُرسل لميتا وقوقل" بدل "فواتير الكاشير" التزاماً بقائمة "لا تدّعي".
3. **العرض في `02` (خدمة كاملة بآلاف الريالات + ضمان أداء)** يتحول إلى: الأساس $39 + التجربة، و"313 تدير إعلاناتك $400" هي النسخة "Done-for-you" (Upsell).

## 6. قالب SOP
`وعي بالمشكلة عالي + سعر منخفض + تجربة مجانية` → **VSL → تجربة → تفعيل → دفع → Upsell**
`وعي منخفض أو حاجة لتقسيم` → **Quiz Funnel**
`سعر عالي / خدمة مخصصة` → **VSL → Strategy Call** (إن سمحت قواعد البراند)
